# Lead operations (authorized staff only)

Cloudflare D1 console access must be limited to authorized operators. Until a notification provider is chosen and verified, check new leads regularly in the dashboard using `SELECT id, lead_type, name, email, phone, created_at, status FROM leads WHERE status = 'new' ORDER BY created_at DESC LIMIT 50;`. This is an operator-only console query, **not** a public website route. A future transactional alert provider is optional and must have explicit credentials, tested delivery and an authenticated server-side adapter; Proton mailbox and Constant Contact are not assumed to send alerts.

To export or delete an identified record, confirm the requester's identity and applicable legal/retention requirements first, then use a restricted D1 console query with a bound/verified ID: `SELECT * FROM leads WHERE id = ?;` or `DELETE FROM leads WHERE id = ?;`. Record the action in an access-controlled operations log (not this repository). Agree on a retention period and backup/restore procedure before collecting real inquiries. Run migrations on preview first and take a backup before production changes; avoid destructive schema rollback with live leads.
