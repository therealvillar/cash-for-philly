# CashForPhilly Copilot and deployment starter kit

This directory is a historical prompt/brand kit, not a separate website project. The current site and canonical repository are [`therealvillar/cash-for-philly`](https://github.com/therealvillar/cash-for-philly). Do not create a replacement repository or copy the site into a new local folder.

Use the root [`README.md`](../../README.md) and [`docs/deploy-cloudflare.md`](../../docs/deploy-cloudflare.md) for current project and deployment instructions. The root docs take precedence over older prompt or runbook text in this kit.

Kit references:

- `COPILOT_MASTER_PROMPT.md`: historical site implementation requirements, updated to preserve the existing repository identity and deployment-preparation scope.
- `brand/` and `asset-imports/`: legacy design and provenance references. The approved original asset source is the root `cashforphilly-brand-kit/`; do not use restricted trademark illustrations.
- `deployment/CLOUDFLARE_DEPLOYMENT_RUNBOOK.md`: points to the current root runbook.

## Production approval gates

- Owner-approved legal/business identity, notices, disclosures, and monitored contact mailbox.
- Isolated preview/production D1 and Turnstile settings, migrations, and end-to-end tests.
- Separately approved, verified investor opt-in if enabled; seller/agent inquiry is not a subscription.
- Owner approval of source provenance and commercial asset rights.
- Full DNS baseline, preservation of Proton and Constant Contact email records, tested mail/web behavior, and verified rollback.

The site has not been deployed by preparing this repository. Passing local checks does not satisfy production approval.
