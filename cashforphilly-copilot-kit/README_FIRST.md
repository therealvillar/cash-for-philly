# CashForPhilly - Copilot build/deployment starter kit

## What this contains

- `COPILOT_MASTER_PROMPT.md`: Complete copy/paste instruction for GitHub Copilot Agent. It directs Copilot to create a real Astro site, secure lead forms, tests, and Cloudflare Pages Git deployment.
- `brand/design-tokens.json`: Color palette, typography, layout and editorial source of truth reconstructed from the prior project.
- `brand/brand-theme-guide.md`: Brand implementation rules.
- `asset-imports/README.md`: Manifest describing the artwork packages you need to add from the previous campaign.
- `deployment/CLOUDFLARE_DEPLOYMENT_RUNBOOK.md`: Exact release order and account-level setup.

## Prepare before starting in VS Code

1. Create a new local folder `cashforphilly-site` and open it in VS Code.
2. Copy the contents of this ZIP into it.
3. Download the original image/brand archives from the previous CashForPhilly marketing conversation and place the files inside `asset-imports/` (or copy the extracted originals there). Do not substitute machine-generated art for the master logo.
4. Open `COPILOT_MASTER_PROMPT.md`, copy its complete contents, and paste into **GitHub Copilot Chat > Agent** (not a simple autocomplete file edit). Prefer a workspace with terminal and file-edit permissions so the agent can actually write files and run tests.
5. Review changes, confirm business identity/legal details, and authorize any external GitHub or Cloudflare actions only within official tools/browser workflows.
